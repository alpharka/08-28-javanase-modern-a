

## Panduan Customization

Panduan lengkap untuk mengganti data pasangan, acara, galeri, musik, warna, tipografi, RSVP, guestbook, serta navigasi horizontal tersedia di [`CUSTOMIZATION.md`](./CUSTOMIZATION.md).

Sebelum membagikan undangan, ikuti checklist pada dokumen tersebut dan jalankan `pnpm check` serta `pnpm build`.
